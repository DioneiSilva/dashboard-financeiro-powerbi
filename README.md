\# 📊 Dashboard Financeiro - Fluxo de Caixa | Power BI



\## 📌 Sobre o Projeto



Este projeto foi desenvolvido com o objetivo de criar um dashboard financeiro interativo para análise de fluxo de caixa utilizando Power BI.



O painel permite acompanhar indicadores financeiros, entradas, despesas, saldo inicial, saldo final e análise temporal das movimentações financeiras, auxiliando na visualização e interpretação dos dados de forma clara e estratégica.



\---



\## 🎯 Objetivos do Dashboard



\- Monitorar entradas e despesas financeiras

\- Acompanhar saldo financeiro ao longo do tempo

\- Identificar variações financeiras mensais

\- Facilitar análises por categoria e centro de custos

\- Criar visualizações interativas para apoio à tomada de decisão



\---



\## 🛠️ Tecnologias Utilizadas



\- Power BI

\- Power Query

\- DAX

\- Excel



\---



\## 📈 Recursos e Funcionalidades



\- KPIs financeiros

\- Gráfico de cascata para análise do fluxo de caixa

\- Gráfico de colunas para análise de despesas por categoria

\- Indicador de margem financeira

\- Interatividade entre os gráficos

\- Modelagem de dados com tabela fato e dimensão

\- Criação de tabela calendário

\- Medidas DAX para cálculos financeiros

\- Padronização estrutural de tabelas e colunas



\---



\## 🧠 Conceitos Aplicados



\- Modelagem dimensional

\- Relacionamento 1:N

\- Tabela calendário

\- Contexto de filtro

\- Medidas DAX

\- Storytelling com dados
